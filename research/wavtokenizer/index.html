WavTokenizer

WavTokenizer 明确把 codec 做成 audio language modeling 前端：高效、低 token rate、可服务语音与音乐，让离散 acoustic token 更像上层模型的输入语言。

论文精讲：WavTokenizer 为什么叫 tokenizer 而不只是 codec

模型解析encoder、单量化器和逆傅里叶 decoder
  • encoder 加强上下文建模，把 waveform 压到低帧率 latent。
  • 单量化器在更大的 VQ 空间里产出离散 acoustic token，目标是让序列尽量短。
  • decoder 用逆傅里叶结构和上采样恢复 waveform，强调 audio LM 前端效率。
创新点面向 audio language modeling 反推 codec 设计
  • 指标不只看重建音质，还看 token rate、序列长度和语言模型可建模性。
  • 40 或 75 tokens/s 的设置让 24 kHz 音频压成非常短的离散序列。
  • 扩展上下文、改进 attention 和更大 VQ 空间都是为 token 更稳定、更少冗余服务。
损失函数重建、判别和码本目标一起约束 token
  • reconstruction / spectral loss 负责基础内容和频谱一致性。
  • multi-scale discriminator 提升不同时间尺度下的真实感。
  • VQ / commitment 相关目标约束单量化器，使高压缩 token 不至于失去可解码性。
训练策略用训练侧模块补足极端压缩带来的信息损失
  • 扩展上下文窗口增强长程依赖，避免低 token rate 下内容断裂。
  • 改进 attention network 提升建模稳定性和训练效率。
  • 训练时同时关注 codec reconstruction 和 audio LM 友好的 token 形态。
结果分析低 token rate 是优势，也是风险
  • 短序列显著降低 audio LM 训练和推理成本。
  • 单量化器让接口更简单，但所有信息都挤进一条码流，容量压力更大。
  • 它适合做生成模型前端；如果只追求极致音质，DAC / EnCodec 类多码本方案仍有优势。
