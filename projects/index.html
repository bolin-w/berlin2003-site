Project 01 Speech Frontend Research Site

把 semantic token、acoustic codec 和桥接方案整理成可回看的论文精讲库。下一步补实验复现、音频样例和对比表。

Project 02 Low Bitrate Codec Evaluation

建立更稳定的评估口径：码率、token rate、听感、说话人保持、延迟和训练成本分开看，避免被单一指标带偏。

Project 03 Personal Site Deployment

静态页面、Caddy 配置、私密工作台和 AI 服务都进入版本管理。后面继续补 README、部署说明和自动同步脚本。

Project 04 Local Subtitle Video Library

本地完成字幕压制，服务器负责保存、列表和播放。这个项目偏日常工具，重点是上传流程、权限和观看体验。

Project 05 Research Writing System

论文阅读固定拆成模型解析、创新点、损失函数、训练策略、结果分析和局限，让每篇文章都能横向比较。

Project 06 Future Demo Slots

后续接入音频样例、AB 对比、码率滑条和结构图交互，让研究页从“读一读”变成“看得出差别”。
