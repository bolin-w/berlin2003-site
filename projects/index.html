Project 01 Speech Frontend Research Site

把 semantic token、acoustic codec 和桥接方案整理成可导航的论文精讲库。当前 research 已经是主内容区，后续继续补实验复现和对比表。

Project 02 Low Bitrate Codec Evaluation

建立一套更稳定的评估口径：码率、token rate、听感、说话人保持、延迟和训练成本分开看，不把单一指标当最终结论。

Project 03 Personal Site Deployment

静态页面、Caddy 配置、私密工作台和 AI 服务都进入版本管理。下一步适合补 README、部署说明和自动同步脚本。

Project 04 Local Subtitle Video Library

本地完成字幕压制，服务器只负责存储、列表和播放。这个项目偏工具化，重点是上传流程、权限和播放器体验。

Project 05 Research Writing System

把论文阅读拆成固定栏目：模型解析、创新点、损失函数、训练策略、结果分析和局限。这样每篇文章都有可比较的结构。

Project 06 Future Demo Slots

后续可以接入音频样例、AB 对比、码率滑条和模型结构图交互，让研究页从“阅读”变成“可检查”。
