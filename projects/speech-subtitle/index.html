语音字幕识别

用语音识别模型把视频里的语音转成文字，翻译成中文字幕后压入成片。整条链路在本地完成，服务器只负责收藏与放映。

模块一

整体流程：从视频到中文字幕片

整个工具是一个本地 PowerShell 脚本驱动的管线，把视频放进 input 目录，运行脚本即可自动走完全部流程。

  • 读取字幕源 — 优先提取内嵌文本字幕轨；没有则尝试 OCR 图片字幕；都没有才走语音识别
  • 语音识别 — 用 faster-whisper 对音轨做语音转文字，生成带时间戳的原文
  • 翻译润色 — 调用翻译接口把任意语言字幕转成简体中文，再做一次 AI 审核让表达更自然
  • 字幕压制 — 用 ffmpeg 把中文字幕烧录进 MP4，输出 H.264 + AAC 的浏览器友好格式
  • 上传归档 — 可选把成品上传到网站视频库，在放映室页面展示

模块二

字幕来源：三条路自动降级

工具默认用 auto 模式，按优先级自动选择字幕来源，也可以手动指定。

  • 文本字幕轨 — MKV、MP4 内嵌的 SRT/ASS 等文本字幕，直接提取翻译
  • PGS 图片字幕 — 蓝光常见格式，需通过 Subtitle Edit + Tesseract OCR 转成文本；未装 OCR 时自动回退语音识别
  • 语音识别 — 视频没有任何可用字幕时，提取音轨用 faster-whisper 听写
  • 支持 -SubtitleMode asr 强制走语音识别，-SubtitleMode embedded 强制只用内置字幕

模块三

语音识别：faster-whisper

用 faster-whisper 做本地 GPU 推理，不依赖外部 API，数据不出本机。

  • 可选模型：tiny、base、small、medium、large-v3
  • 默认 medium，比 small 更不容易漏人声；追求准确率用 large-v3
  • 支持指定源语言（-SourceLanguage ja）提高识别稳定性
  • 默认启用 VAD 语音检测；背景音太重时可关闭（-NoVad）
  • 模型文件较大，首次运行会自动下载并缓存到指定目录

模块四

翻译与 AI 润色

识别出的原文字幕通过翻译接口统一转成简体中文，再做一轮审核润色，让字幕读起来更自然。

  • 需要在配置文件中填写 API Key，支持任意源语言转简体中文
  • 翻译完成后自动做二次 AI 审核，修正断句、口语化表达与不通顺的地方
  • -NoTranslate 跳过翻译，保留原文字幕
  • -NoReview 只做机器直译，不做二次润色
  • 输出 .zh.vtt 和 .zh.srt 两种格式，方便后续复用

模块五

字幕压制与上传

字幕文件准备好后，用 ffmpeg 烧录进视频画面。压制参数可调，成品可直接上传到网站。

  • 输出统一为 MP4：H.264 视频 + AAC 音频，浏览器直接播放
  • 支持 -BurnOnly 跳过识别和翻译，直接用已有的字幕文件重新压制
  • CRF 可调（默认平衡画质与体积），临时文件可指定到非系统盘
  • 支持 -Upload 压制完成后直接上传到网站视频库
  • 输入格式支持 mp4、mkv、mov、webm、m4v

附：GUI 工作台

可视化操作界面

除了命令行，还做了一个 PowerShell GUI 工作台，提供按钮式操作，不需要记参数。

  • 打开 input 文件夹 — 快速放入待处理视频
  • 生成字幕 — 只做识别 + 翻译，输出字幕文件
  • 压制字幕视频 — 完整流程，生成带字幕的 MP4
  • 压制并上传服务器 — 压制完成后直接推到视频库
